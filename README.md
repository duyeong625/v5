# CAD 자동 견적 V5 — GitHub Pages 정적 버전

## 설치

1. ZIP 압축을 풉니다.
2. `index.html`, `style.css`, `app.js`, `drawing-data.json`을 GitHub 저장소 **최상위**에 업로드합니다.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. `https://<계정>.github.io/<저장소>/`로 접속합니다. 예: `https://duyeong625.github.io/v5/`.
5. 로컬 테스트는 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속을 권장합니다. `file://`로 열면 JSON fetch가 차단될 수 있습니다.

## 구현 기능

- 실제 `도면1.dxf`의 Rhino Make2D SPLINE 중 **길이가 0이 아닌 1,605개**를 Python ezdxf에서 허용오차 1.5 도면 단위로 선분화한 JSON을 포함.
- SVG 선 클릭 공정 색상 지정(절단 파랑, 절곡 주황, 용접 빨강, 홀 초록), 숨김선 표시, 다중 선택, 확대/이동.
- 검증 확인한 선만 공정비에 반영. 절단/용접 길이는 선택 선의 선분화 길이 × 도면단위 변환값, 절곡/홀은 승인된 선 수를 횟수로 사용.
- 전개 면적은 사용자 검증 입력 필수. SUS304 밀도 7,930kg/m³ 가정. 자체 단가, 간접비, 목표 매출총이익률, VAT 계산.
- 단가 로컬 저장 및 JSON 백업/복원, 견적 이력 로컬 저장 및 JSON 백업/복원, 견적 CSV 출력.
- 신규 ASCII DXF 업로드는 LINE, 직선 LWPOLYLINE, CIRCLE, ARC의 기본 2D 객체만 지원. SPLINE, bulge 곡선, POLYLINE, INSERT/BLOCK, 치수, 복잡한 변환은 **새 DXF 업로드에서 미지원**. 기본 제공 도면의 SPLINE만 사전 변환되어 선택 가능.

## 중요한 제한

- `도면1.dxf`는 INSUNITS=0(미지정). 화면의 `길이 단위 변환(mm/도면단위)` 기본값 1은 임시값이므로 치수로 교정해야 합니다.
- Rhino Make2D 투상도는 숨김선/중복 투상선이 많습니다. 선택 선의 길이가 실제 절단/용접 길이 또는 실제 절곡선이라는 보장이 없습니다. 담당자가 **중복 제외, 공정 종류, 실제 작업 길이, 절곡 횟수**를 확인해야 합니다.
- 절곡 비용은 승인한 곡선 1개당 1회로 계산하는 단순 모델입니다. 분할 선분/다중선/공구 조건에 따라 실제 횟수와 다릅니다.
- 원판 배치·네스팅·전개 형상 자동 복원, 3D 절곡 복원, 자동 용접선 인식, DWG 직접 해석은 구현하지 않았습니다.
- 견적 단가는 **예시값**으로 제공됩니다. 실제 단가를 입력하세요.
- GitHub Pages는 정적 호스팅입니다. 이력과 단가는 각 브라우저 localStorage에만 보관되며 직원 간 공유되지 않습니다. 기밀 도면/단가를 공개 저장소에 업로드하지 마세요.
- 정식 사용 전 실제 도면 검수 및 수작업 견적과 대조, 백업 및 권한 관리가 필요합니다.

## 테스트

- `node --check app.js` 문법 검사.
- `python -m http.server 8000`으로 실행하고 도면이 보이는지 확인.
- 절단/절곡/용접 공정을 지정하고 검증 확인 체크 후 승인 → 전개 면적과 단가 입력 → 합계 계산.
- 이력 저장 → 새로고침 → 이력 불러오기 → JSON 백업/복원.
- 다른 DXF 업로드 시 미지원 SPLINE 안내 확인.
